# BulSU Tools

**Free campus tools for Bulacan State University, built by BulSU students.**

[bulsu.tools](https://bulsu.tools) · [Fork kit](https://fork.bulsu.tools) · [GitHub](https://github.com/bulsutools)

</div>

We build and run free web apps for the Bulacan State University community (Malolos Campus 1 + Campus 2). Community-maintained, MIT-licensed where applicable. Not an official BulSU project.

Most of the stack is forked from [UPLB Tools](https://github.com/uplbtools) — the [Campus Tools fork kit](https://fork.bulsu.tools) documents how campus forks work.

## Projects

| Project | What it does |
| --- | --- |
| [**Room TBA**](https://github.com/bulsutools/room-tba) | Campus map + class finder for BulSU Malolos: buildings, colleges, room pins, offline PWA. Fork of [uplbtools/room-tba](https://github.com/uplbtools/room-tba). [Live](https://room-tba.bulsu.tools) |
| [**Geary**](https://github.com/bulsutools/geary) | Student-managed information portal for BulSUans, by BulSUans. [Live](https://geary.bulsu.tools) |
| [**GWA Calculator**](https://github.com/bulsutools/gwa-calculator) | GWA and honors estimator that runs entirely in the browser — grades never leave the device |
| [**ALAB Grade Tools**](https://github.com/bulsutools/alab-grade-tools) | Browser extension adding GWA, term breakdown, subject search, and export to the ALAB SMS grades page |
| [**alab-gradesim**](https://github.com/bulsutools/alab-gradesim) | GradeSim fork for BulSU: GWA calculator, Latin honors simulator, course planner |
| [**fork-kit**](https://github.com/bulsutools/fork-kit) | Campus Tools fork wiki + org bootstrap template — how campus forks of UPLB Tools get made. [Live](https://fork.bulsu.tools) |
| [**website**](https://github.com/bulsutools/website) | [bulsu.tools](https://bulsu.tools) org landing site (fork of [uplbtools/website](https://github.com/uplbtools/website)) |

## Contributing

Start with issues on [room-tba](https://github.com/bulsutools/room-tba/issues) or [geary](https://github.com/bulsutools/geary/issues). Wrong campus data and QA reports are contributions too — the Room TBA editor (`/?editor=login`) is how pins and places get fixed.
